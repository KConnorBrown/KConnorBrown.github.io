# Pillar Build Order

1. Development portfolio (projects, case studies, SQL playground).
2. Visual art archive (chronological gallery + interactive viewer).
3. Photo journal grid (editable, media pipeline).
4. Writing (essays, notes, drafts — password protected).
5. Interior design (subset of journal grid + featured projects).

This ordering emphasizes quickly showing professional work while laying the
foundation for a cohesive visual/interactive archive.

## Implemented

- Django site with PostgreSQL (site DB + playground DB)
- SQL playground at `/playground/sql/` (official tutorial datasets)
- Portfolio, writing, and journal app scaffolding
- Vercel deployment docs in `docs/deploy.md`
